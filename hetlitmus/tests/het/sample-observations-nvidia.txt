# harness end to end against the new NVIDIA oracle.
#
# Since Task 3 the oracle CONTAINS Disallowed rows (the two-sided `-2s' tests
# complete a morally-strong cross-device pair), so the harness can now exercise
# ALL THREE result branches:
#   - MATCH      : Allowed seen/not-seen, or Disallowed NOT seen ("forbidden, not
#                  seen") -- the expected, healthy case for a Disallowed test
#   - MISMATCH   : a Disallowed (forbidden) outcome WAS observed -- a genuine
#                  model-violation finding (the falsification the pipeline hunts)
#   - NO-ORACLE  : the test has verdict NO-ORACLE, or is absent from the oracle
#
# HONESTY: an observed weak outcome makes Allowed robust; a NON-observation never
# proves Disallowed (a Disallowed test merely seen as Never is MATCH "forbidden,
# not seen", NOT a confirmation).  Only an OBSERVED forbidden outcome is a hard
# contradiction (MISMATCH).
#
# A Condition line before an Observation sets that row's QUANT (exists/forall);
# rows with no Condition line default to exists.
