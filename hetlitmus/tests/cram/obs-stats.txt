# Synthetic log fixture for oracle-compare.sh's STATISTICS section (Layer-1 cram).
# Five tests, one per reporting path: a relaxation exhibited on a canary-only
# harness; a sighting corroborated across three clean runs with mu(T) hot; a null
# over eight usable runs with a live mu(T) stream; the same null shape over only
# two (the low-effort NEVER, and the row that shows effort is disclosed rather
# than priced); and a row whose every cell was COLD (VOID).
# The HetObs / HetVerdict / HetStats lines were PRINTED BY het_verdict.h's own
# printers -- het_obs_record_print, het_verdict_print, het_stats_print -- over
# synthetic het_obs_record streams, the way hetlitmus/verify/statscheck.py drives
# them.  They have to be the real thing: oracle-compare.sh reprints
# het_stats_print's block instead of re-deriving it.  NEVER HAND-EDIT A DATA LINE
# BELOW; regenerate and restore this header.
#
# REGENERATION.  There is no committed generator: the driver is written ad hoc,
# the way statscheck.py writes its own C_MAIN.  From the repo root --
#   d=$(mktemp -d)
#   litmus7 -set-libdir litmus/libdir -o "$d" hetlitmus/tests/het/MP-cg-sys-fence-2s.litmus
#   h="$d/MP-cg-sys-fence-2s"          # any het emission ships het_verdict.h
#   cat > "$d/drv.c" <<'EOF'
#   #include "het_verdict.h"
#   /* one memset-zeroed het_obs_record per (test,run) below, rec_magic stamped
#      HET_REC_MAGIC and the other fields set from that row's own HetObs line;
#      then het_obs_record_print + het_verdict_print per record, and
#      het_stats_compute + het_stats_print once per test, followed by the four
#      litmus scaffolding lines (Test / Histogram / Condition / Observation). */
#   EOF
#   gcc -std=c99 -O2 -Wall -Wno-unused-function -I "$h" "$d/drv.c" -o "$d/drv" -lm
#   "$d/drv" > obs-stats.txt
# The per-window control streams are NOT in the HetObs line and have to be
# rebuilt: SB-sys / MP-sys-F / SB-sys-2s draw each window from a Poisson with
# mean ~0.4 (an LCG, so the numbers are machine-independent), and MP-sys-2s
# fills each window from one slow cosine cycle across the run.  Every stream's
# total is its own sum, or the aggregate would flag HET_ST_WIN_DESYNC.  The
# recipe fixes neither the LCG seed nor the cosine's amplitude, so a regeneration
# from records is not reproducible from this header alone; the five HetStats
# BLOCKS, however, are -- het_stats_print is a pure function of het_stats_t, and
# the machine line carries every field of one except the two KS window counts
# (fixed by win_n) and n_mu_hot, which each NEVER block states in words.  Those
# blocks were last reprinted from exactly that.
# The HetObs line dumps every other field of its record, so the rest of the
# driver is reconstructible from this fixture.
#
# KNOWN GAP: no gate binds this text to the live printers.  If het_verdict.h's
# wording changes, this fixture goes stale and oracle-negatives.t stays green --
# those pins exercise oracle-compare.sh's reprint logic, not the printer itself.
